# Sabong Tracker

A mobile-friendly HTML5 tracker for recording Sabong results, viewing history, streaks, and probability suggestions.

## Features

- Main view for submitting start numbers, winner, and side
- Undo / Redo support for last entry operations
- Reset data while preserving settings
- Full history table and combo percentage graph
- Meron/Wala and Lyamado/Dehado streak views
- Statistical suggestion with confidence score
- Settings tab to add custom patterns for prediction

## Usage

1. Open `index.html` in your browser.
2. Enter a start number, select winner and side, then click `Submit`.
3. Use the tabs to navigate between views.
4. Add patterns in Settings to influence Pusta Na suggestions.

## Notes

- The app stores entries and patterns in browser local storage.
- `Reset` clears recorded entries but does not delete saved patterns.
